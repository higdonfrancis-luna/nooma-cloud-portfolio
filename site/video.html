Same product, two clouds

A 9-minute walkthrough of how the Strategic Partners CRM was rebuilt as a serverless application on AWS, the pieces it uses, and how AWS compares with Cloudflare.

Covered in the video:

  • CloudFront and a private S3 bucket with Origin Access Control
  • API Gateway (HTTP API) with throttling, and Lambda on ARM
  • DynamoDB designed around the questions the app asks
  • IAM least privilege, CDK and CloudFormation, and GitHub Actions deploys over OIDC with no stored keys
  • A Command Center that answers plain-English questions with no AI
